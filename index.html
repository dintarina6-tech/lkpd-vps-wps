Fase 1: Pengenalan Konsep VPS & Cloud

1. Shared Hosting

Shared Hosting adalah layanan hosting yang digunakan bersama oleh banyak pengguna dalam satu server.

2. Dedicated Server

Dedicated Server adalah server khusus yang digunakan oleh satu pengguna sehingga sumber dayanya tidak dibagi dengan pengguna lain.

3. Amazon Lightsail

Amazon Lightsail adalah layanan cloud yang mudah digunakan untuk membuat dan mengelola VPS dengan biaya yang sederhana.

4. Amazon EC2

Amazon EC2 adalah layanan AWS yang menyediakan server virtual dengan pengaturan kapasitas dan sumber daya yang fleksibel.
